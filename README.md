# Times Clicker Game ⏰🎮


## 🇺🇦 **Українська версія**

### 🕹️ Гра Times Clicker
Інтерактивна клікер-гра з вражаючими візуальними ефектами та фонк-музикою!

### ✨ Особливості
- 🎵 Вбудований музичний плеєр з 6 фонк-треками
- 📱 Підтримка PWA (можна встановити на пристрій)
- 🎨 Кастомізація скінів годинника
- 📊 Глибока статистика та досягнення
- 🔄 Система престижу з множниками
- 📱 Версії для ПК та мобільних пристроїв
- 🎯 Система комбо та частинки

### 🎮 Як грати
1. Клікай на годинник, щоб заробляти час
2. Купуй апгрейди для більшого часу за клік
3. Відкривай нові скіни
4. Виконуй досягнення
5. Використовуй престиж для отримання множників

### 🚀 Онлайн версія
Грати зараз: https://danik25326.github.io/timeclicker/

### 🛠️ Технології
- HTML5, CSS3, JavaScript
- PWA (Service Worker, Manifest)
- LocalStorage для збереження прогресу
- Частинки (particles) для візуальних ефектів

## 🇬🇧 **English Version**

### 🕹️ Time Clicker Game
An interactive clicker game with stunning visual effects and phonk music!

### ✨ Features
- 🎵 Built-in music player with 6 phonk tracks
- 📱 PWA support (installable on your device)
- 🎨 Customizable clock skins
- 📊 Deep statistics & achievements system
- 🔄 Prestige system with multipliers
- 📱 Mobile & PC versions
- 🎯 Combo system & particle effects

### 🎮 How to Play
1. Click the clock to earn time
2. Buy upgrades for more time per click
3. Unlock new skins
4. Complete achievements
5. Use prestige to get multipliers

### 🚀 Live Demo
Play now: https://danik25326.github.io/timeclicker/

### 🛠️ Technologies
- HTML5, CSS3, JavaScript
- PWA (Service Worker, Manifest)
- LocalStorage for game saves
- Particle effects for visuals
